# 易淘商城 · 接口文档

| 项目 | 内容 |
| --- | --- |
| 服务地址 | `http://127.0.0.1:5001` |
| 数据格式 | `application/json`（请求与响应） |
| 字符集 | UTF-8 |
| 鉴权方式 | 请求头 `Authorization: Bearer <token>` |
| 文档版本 | V1.0 |

---

## 1. 通用约定

### 1.1 统一响应格式

**成功**（HTTP 200）：

```json
{
  "code": "OK",
  "data": { }
}
```

**失败**（HTTP 4xx / 5xx）：

```json
{
  "code": "INSUFFICIENT_STOCK",
  "message": "商品「移动电源」库存不足，当前仅剩 3 件"
}
```

> 判断请求是否成功，**看 HTTP 状态码 + `code` 字段**，不要只看 `code`。

### 1.2 错误码表

| code | HTTP | 含义 | 常见触发 |
| --- | --- | --- | --- |
| `OK` | 200 | 成功 | — |
| `INVALID_PARAM` | 400 | 参数无效 | 用户名/密码为空、缺 quantity、数量超上限 |
| `USERNAME_EXISTS` | 400 | 用户名已存在 | 注册重名 |
| `LOGIN_FAILED` | 401 | 用户名或密码错误 | 登录失败 |
| `UNAUTHORIZED` | 401 | 未登录或 token 失效 | 未带 token、token 无效 |
| `PRODUCT_NOT_FOUND` | 404 | 商品不存在 | 查询/加购不存在商品 |
| `PRODUCT_OFF_SALE` | 400 | 商品已下架 | 加购/下单下架商品 |
| `CART_NOT_FOUND` | 404 | 购物车记录不存在 | ID 不存在、或操作他人购物车 |
| `EMPTY_CART` | 400 | 未选择商品 | 下单时 cartIds 为空 |
| `INSUFFICIENT_STOCK` | 400 | 库存不足 | 下单数量 > 库存 |
| `ORDER_NOT_FOUND` | 404 | 订单不存在 | 查询不存在订单 |
| `NOT_FOUND` | 404 | 接口不存在 | 访问未定义接口 |
| `INTERNAL_ERROR` | 500 | 服务端异常 | 未捕获错误 |

### 1.3 数据库连接（Navicat）

| 项 | 值 |
| --- | --- |
| 主机 | `127.0.0.1` |
| 端口 | `3306` |
| 用户 | `root` |
| 密码 | `123456` |
| 数据库 | `easybuy_mall` |

## 2. 系统接口

### 2.1 健康检查

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/health` |
| 鉴权 | 否 |

**响应示例**

```json
{
  "code": "OK",
  "data": { "status": "UP", "db": "10.4.14-MariaDB" }
}
```

### 2.2 重置数据（测试便利接口）

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/dev/reset` |
| 鉴权 | 否 |

把数据恢复到初始状态（清空业务数据、重置库存、重灌 seed）。

```json
{ "code": "OK", "data": { "reset": true } }
```

## 3. 用户接口

### 3.1 注册

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/user/register` |
| 鉴权 | 否 |

**请求体**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名，唯一 |
| password | string | 是 | 密码 |
| phone | string | 否 | 手机号 |

```json
{ "username": "tester01", "password": "123456", "phone": "13800000000" }
```

**成功响应**（200）

```json
{ "code": "OK", "data": { "userId": 4, "username": "tester01" } }
```

**失败示例**

| 场景 | HTTP | code |
| --- | --- | --- |
| 用户名为空 | 400 | `INVALID_PARAM` |
| 密码为空 | 400 | `INVALID_PARAM` |
| 用户名已存在 | 400 | `USERNAME_EXISTS` |

### 3.2 登录

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/user/login` |
| 鉴权 | 否 |

**请求体**

```json
{ "username": "demo", "password": "123456" }
```

**成功响应**

```json
{ "code": "OK", "data": { "token": "3f2a9c1e8b7d4a6f0e5c2b9a7d4e1f8c" } }
```

**失败**：用户名不存在或密码错误，均为 `401 LOGIN_FAILED`。

> 后续所有需要登录的接口，请把 token 放进请求头：
> `Authorization: Bearer <token>`

### 3.3 查询当前用户资料

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/user/profile` |
| 鉴权 | **是** |

**成功响应**

```json
{ "code": "OK", "data": { "id": 3, "username": "demo" } }
```

**失败**：未带 token / token 无效 → `401 UNAUTHORIZED`。

## 4. 商品接口

### 4.1 商品列表

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/products` |
| 鉴权 | 否 |

**查询参数**

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| page | int | 否 | 1 | 页码，从 1 开始 |
| size | int | 否 | 10 | 每页条数 |
| category | string | 否 | — | 分类筛选，如 `数码` |

**请求示例**

```
GET /api/products?page=1&size=10&category=数码
```

**成功响应**

```json
{
  "code": "OK",
  "data": {
    "total": 3,
    "page": 1,
    "size": 10,
    "items": [
      { "id": 1, "name": "无线蓝牙耳机", "category": "数码",
        "price": 199.0, "stock": 50, "status": "ON_SALE",
        "description": "主动降噪，续航 30 小时" }
    ]
  }
}
```

> 已下架商品（`status != ON_SALE`）的 `stock` 一律返回 0。

### 4.2 商品详情

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/products/{productId}` |
| 鉴权 | 否 |

**路径参数**：`productId`（int）

**成功响应**

```json
{
  "code": "OK",
  "data": { "id": 3, "name": "移动电源", "category": "数码",
            "price": 129.0, "stock": 3, "status": "ON_SALE",
            "description": "20000mAh 双向快充" }
}
```

**失败**：`404 PRODUCT_NOT_FOUND`。

## 5. 购物车接口

> 全部需要鉴权。所有操作只作用于**当前登录用户自己的**购物车。

### 5.1 加入购物车

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/cart/items` |
| 鉴权 | 是 |

**请求体**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| productId | int | 是 | 商品 ID |
| quantity | int | 是 | 数量 |

```json
{ "productId": 3, "quantity": 2 }
```

**成功响应**

```json
{ "code": "OK", "data": { "cartId": 1, "quantity": 2 } }
```

> 同一商品重复加购，`quantity` 会在原值上**累加**。
> ⚠️ 本版本对 `quantity` 不做校验：`0`、`-3`、`999` 都会被接受（BUG-005）。

**失败示例**

| 场景 | HTTP | code |
| --- | --- | --- |
| 商品不存在 | 404 | `PRODUCT_NOT_FOUND` |
| 商品已下架 | 400 | `PRODUCT_OFF_SALE` |
| 缺少 quantity | 400 | `INVALID_PARAM` |

### 5.2 查询购物车

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/cart/items` |
| 鉴权 | 是 |

**成功响应**

```json
{
  "code": "OK",
  "data": {
    "items": [
      { "id": 1, "product_id": 3, "product_name": "移动电源",
        "price": 129.0, "quantity": 2, "stock": 3 }
    ]
  }
}
```

### 5.3 修改购物车数量

| 项 | 值 |
| --- | --- |
| 方法 | `PUT` |
| 路径 | `/api/cart/items/{cartId}` |
| 鉴权 | 是 |

**请求体**：`{ "quantity": 5 }`

**成功响应**：`{ "code": "OK", "data": { "cartId": 1, "quantity": 5 } }`

**失败**：记录不存在 **或属于他人** → `404 CART_NOT_FOUND`。

### 5.4 删除购物车记录

| 项 | 值 |
| --- | --- |
| 方法 | `DELETE` |
| 路径 | `/api/cart/items/{cartId}` |
| 鉴权 | 是 |

**成功响应**：`{ "code": "OK", "data": { "removed": 1 } }`

**失败**：记录不存在或属于他人 → `404 CART_NOT_FOUND`。

## 6. 订单接口

### 6.1 创建订单

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/orders` |
| 鉴权 | 是 |

**请求体**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| cartIds | int[] | 是 | 要下单的购物车记录 ID 列表 |

```json
{ "cartIds": [1, 2] }
```

**成功响应**

```json
{
  "code": "OK",
  "data": {
    "id": 1, "user_id": 3, "amount": 258.0, "status": "PENDING",
    "pay_type": null,
    "created_at": "2026-10-05 15:30:00", "paid_at": null,
    "items": [
      { "product_id": 3, "product_name": "移动电源",
        "price": 129.0, "quantity": 2 }
    ]
  }
}
```

**失败示例**

| 场景 | HTTP | code |
| --- | --- | --- |
| cartIds 为空 | 400 | `EMPTY_CART` |
| 购物车记录不存在 / 不属于我 | 404 | `CART_NOT_FOUND` |
| 商品已下架 | 400 | `PRODUCT_OFF_SALE` |
| 数量超过 99 | 400 | `INVALID_PARAM` |
| 库存不足 | 400 | `INSUFFICIENT_STOCK` |

> ⚠️ 本接口存在**并发超卖**缺陷（BUG-003）：两个请求同时下单同一低库存商品时，
> 都可能通过库存校验，最终库存被扣成负数。

### 6.2 订单列表

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/orders` |
| 鉴权 | 是 |

**成功响应**

```json
{
  "code": "OK",
  "data": {
    "items": [
      { "id": 1, "user_id": 3, "amount": 258.0, "status": "PENDING",
        "pay_type": null, "created_at": "2026-10-05 15:30:00", "paid_at": null }
    ]
  }
}
```

### 6.3 订单详情

| 项 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/orders/{orderId}` |
| 鉴权 | 否（**这本身是缺陷**） |

**成功响应**：同 6.1 创建订单的 `data`。

> ⚠️ BUG-004：本接口**不校验订单归属**，任何知道订单号的人都能查到别人的订单，
> 包括商品、金额、时间。取消接口同样。

### 6.4 支付订单

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/orders/{orderId}/pay` |
| 鉴权 | 否（**这本身是缺陷**） |

**请求体**

```json
{ "payType": "ALIPAY" }
```

`payType` 可选，默认 `ALIPAY`。

**成功响应**：订单对象，`status` 变为 `PAID`，`paid_at` 有值。

> ⚠️ BUG-001：**不校验订单当前状态**，一笔已取消（CANCELLED）的订单
> 依然能被支付成功，状态被打回 PAID。

### 6.5 取消订单

| 项 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `/api/orders/{orderId}/cancel` |
| 鉴权 | 否（**这本身是缺陷**） |

**成功响应**：订单对象，`status` 变为 `CANCELLED`，库存回滚。

> ⚠️ BUG-002：**不幂等**。对同一笔订单连续取消两次，库存会被回滚两次
> （50 → 52），凭空多出商品。
> ⚠️ BUG-004：不校验归属，可取消他人订单。

## 8. 导入 Postman / Apifox 的最小请求集合

先在环境变量里设 `baseUrl = http://127.0.0.1:5001`，然后按顺序执行：

```bash
# 1. 登录拿 token
POST {{baseUrl}}/api/user/login
Body: {"username":"demo","password":"123456"}
→ 记下 data.token

# 2. 看商品库存
GET {{baseUrl}}/api/products/3

# 3. 加入购物车
POST {{baseUrl}}/api/cart/items
Header: Authorization: Bearer {{token}}
Body: {"productId":3,"quantity":2}

# 4. 下单
POST {{baseUrl}}/api/orders
Header: Authorization: Bearer {{token}}
Body: {"cartIds":[1]}

# 5. 取消订单（连续调两次，观察库存）
POST {{baseUrl}}/api/orders/1/cancel

# 6. 再次支付已取消的订单（观察状态）
POST {{baseUrl}}/api/orders/1/pay
```
