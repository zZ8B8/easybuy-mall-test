# 接口文档 · 易淘商城

- 基地址：`http://127.0.0.1:5001`
- 请求/响应均为 `application/json; charset=utf-8`
- 鉴权：需登录的接口在请求头带 `Authorization: Bearer <token>`

**统一响应格式**

```json
// 成功
{ "code": "OK", "data": { } }
// 失败
{ "code": "错误码", "message": "错误描述" }
```

## 接口清单

| # | 方法 | 路径 | 说明 | 鉴权 |
|---|---|---|---|---|
| 1 | GET | `/health` | 健康检查 | 否 |
| 2 | POST | `/api/user/register` | 注册 | 否 |
| 3 | POST | `/api/user/login` | 登录，返回 token | 否 |
| 4 | GET | `/api/products` | 商品列表（分页 / 分类） | 否 |
| 5 | GET | `/api/products/{id}` | 商品详情 | 否 |
| 6 | POST | `/api/cart/items` | 加入购物车 | 是 |
| 7 | GET | `/api/cart/items` | 购物车列表 | 是 |
| 8 | PUT | `/api/cart/items/{id}` | 修改购物车数量 | 是 |
| 9 | DELETE | `/api/cart/items/{id}` | 删除购物车条目 | 是 |
| 10 | POST | `/api/orders` | 提交订单 | 是 |
| 11 | GET | `/api/orders` | 我的订单列表 | 是 |
| 12 | GET | `/api/orders/{id}` | 订单详情 | 是 |
| 13 | POST | `/api/orders/{id}/pay` | 支付订单 | 是 |
| 14 | POST | `/api/orders/{id}/cancel` | 取消订单 | 是 |

### 1. GET /health

```json
{ "code": "OK", "data": { "status": "UP" } }
```

### 2. POST /api/user/register

请求：`{ "username": "alice", "password": "abc123", "phone": "15576039320" }`

```json
{ "code": "OK", "data": { "userId": "U00001", "username": "alice" } }
```

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `INVALID_PARAM` | 400 | 用户名或密码为空 |
| `WEAK_PASSWORD` | 400 | 密码长度 < 6 |
| `INVALID_PHONE` | 400 | 手机号非 11 位数字（phone 为空时跳过校验） |
| `USER_EXISTS` | 400 | 用户名已存在 |

### 3. POST /api/user/login

请求：`{ "username": "alice", "password": "abc123" }`

```json
{ "code": "OK", "data": { "token": "T00002" } }
```

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `LOGIN_FAILED` | 401 | 用户不存在或密码错误（不区分，避免枚举用户名） |

### 4. GET /api/products

查询参数：`page`（默认 1）、`size`（默认 10）、`category`（可选）

```json
{
  "code": "OK",
  "data": {
    "total": 6, "page": 1, "size": 10,
    "items": [
      { "id": "P00001", "name": "无线蓝牙耳机", "category": "数码",
        "price": 199.0, "stock": 50, "status": "ON_SALE" }
    ]
  }
}
```

说明：只返回 `status = ON_SALE` 的商品；按 `id` 升序。

### 5. GET /api/products/{id}

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `PRODUCT_NOT_FOUND` | 404 | 商品 ID 不存在 |

### 6. POST /api/cart/items

请求：`{ "productId": "P00001", "quantity": 2 }`

```json
{ "code": "OK", "data": { "cartId": "C00003", "quantity": 2 } }
```

- 同一用户重复加购同一商品 → **累加数量**，不新增条目
- 购物车按用户隔离

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `PRODUCT_NOT_FOUND` | 404 | 商品不存在 |
| `PRODUCT_OFF_SALE` | 400 | 商品已下架 |
| `UNAUTHORIZED` | 401 | 未带 token 或 token 失效 |

### 7. GET /api/cart/items

```json
{ "code": "OK", "data": { "items": [
  { "cart_id": "C00003", "product_id": "P00001", "product_name": "无线蓝牙耳机",
    "price": 199.0, "quantity": 2 }
] } }
```

### 8. PUT /api/cart/items/{id}

请求：`{ "quantity": 5 }` → `{ "code": "OK", "data": { "cartId": "C00003", "quantity": 5 } }`

| 错误码 | HTTP |
|---|---|
| `CART_NOT_FOUND` | 404 |

### 9. DELETE /api/cart/items/{id}

```json
{ "code": "OK", "data": { "removed": "C00003" } }
```

### 10. POST /api/orders

请求：`{ "cartIds": ["C00003", "C00004"] }`

```json
{ "code": "OK", "data": {
  "id": "O00005", "user_id": "U00001", "status": "PENDING",
  "amount": 398.0, "created_at": "2026-09-29 10:00:00", "paid_at": null, "pay_type": null,
  "items": [ { "product_id": "P00001", "product_name": "无线蓝牙耳机",
               "price": 199.0, "quantity": 2 } ]
} }
```

业务规则：
1. 先**统一校验**所有条目库存，任一条不足则整单失败（不做部分下单）
2. 校验通过后**统一扣减**库存，并写库存流水
3. 下单成功后清空对应购物车条目

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `EMPTY_CART` | 400 | `cartIds` 为空 |
| `CART_NOT_FOUND` | 404 | 购物车条目不存在 |
| `INSUFFICIENT_STOCK` | 400 | 库存不足（消息含当前库存） |

### 11. GET /api/orders

`{ "code": "OK", "data": { "items": [ ...订单对象... ] } }` —— 只返回当前用户的订单。

### 12. GET /api/orders/{id}

| 错误码 | HTTP |
|---|---|
| `ORDER_NOT_FOUND` | 404 |

### 13. POST /api/orders/{id}/pay

请求：`{ "payType": "ALIPAY" }`（可选值：`ALIPAY` / `WECHAT` / `CARD`）

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `ORDER_NOT_FOUND` | 404 | 订单不存在 |
| `INVALID_PAY_TYPE` | 400 | 支付方式不支持 |

> ⚠️ 当前实现**未校验订单状态**，已取消订单仍可支付成功 → 见 BUG-001

### 14. POST /api/orders/{id}/cancel

业务规则：取消后释放占用的库存；已支付订单不可取消。

| 错误码 | HTTP | 触发条件 |
|---|---|---|
| `ORDER_NOT_FOUND` | 404 | 订单不存在 |
| `ORDER_PAID` | 400 | 已支付订单不可取消 |

> ⚠️ 当前实现**缺少幂等校验**（重复取消会重复回滚库存 → BUG-002）
> 且**未校验订单归属**（可取消他人订单 → BUG-004）

## 错误码总表

| 错误码 | HTTP | 含义 |
|---|---|---|
| `OK` | 200 | 成功 |
| `INVALID_JSON` | 400 | 请求体不是合法 JSON |
| `INVALID_PARAM` | 400 | 参数为空 |
| `WEAK_PASSWORD` | 400 | 密码强度不足 |
| `INVALID_PHONE` | 400 | 手机号格式错误 |
| `USER_EXISTS` | 400 | 用户名已存在 |
| `LOGIN_FAILED` | 401 | 登录失败 |
| `UNAUTHORIZED` | 401 | 未登录 / token 失效 |
| `PRODUCT_OFF_SALE` | 400 | 商品已下架 |
| `EMPTY_CART` | 400 | 未选择结算商品 |
| `INSUFFICIENT_STOCK` | 400 | 库存不足 |
| `INVALID_PAY_TYPE` | 400 | 支付方式不支持 |
| `ORDER_PAID` | 400 | 已支付订单不可取消 |
| `PRODUCT_NOT_FOUND` | 404 | 商品不存在 |
| `CART_NOT_FOUND` | 404 | 购物车条目不存在 |
| `ORDER_NOT_FOUND` | 404 | 订单不存在 |
| `NOT_FOUND` | 404 | 接口不存在 |
| `INTERNAL_ERROR` | 500 | 服务内部错误 |
